How AutoMap builds a map

  1. Read the layout. PyMuPDF gives every text block with its font size, weight and position. Running headers and page numbers repeated in the margins are dropped, and heading styles are grouped into levels. If the PDF has trustworthy bookmarks, those win.
  2. Keep the author's structure. Headings become the skeleton of the map, so branches match how the document is actually organised. Front matter and references are left out.
  3. Find topics inside long sections. Passages are embedded with MiniLM and clustered (agglomerative, cosine), with the number of topics chosen by silhouette score.
  4. Name things. Class-based TF-IDF proposes phrases that set a cluster apart from its siblings. Those phrases are then re-ranked by embedding similarity with maximal marginal relevance, so the keywords don't repeat each other.
  5. Connect branches. Nodes in different branches whose content is unusually similar (1.5σ above the document's mean) get a red link.

Every label is extracted from the document, so nothing is made up. The evaluation against the original LLM and clustering versions is in the README.
